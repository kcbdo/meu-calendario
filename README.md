# 📅 Meu Calendário

Aplicativo de calendário para organizar a vida diária, desenvolvido como projeto de portfólio.

## ✨ Funcionalidades
- Criar, editar e excluir eventos
- Arrastar eventos entre datas
- Definir lembretes para eventos
- Tema claro/escuro

## 🛠️ Stack
- **Backend:** Laravel 13 (PHP 8.4)
- **Frontend:** Vue.js 3 + Inertia.js
- **Banco de dados:** MySQL
- **Servidor:** Nginx

## 🚀 Como rodar localmente

# Clone o repositório
git clone git@github.com:kcbdo/meu-calendario.git
cd meu-calendario

# Instale as dependências
composer install
npm install

# Configure o ambiente
cp .env.example .env
php artisan key:generate

# Rode o servidor
php artisan serve
