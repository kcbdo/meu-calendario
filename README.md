# 📅 Meu Calendário

Aplicativo de calendário para organizar a vida diária.

## Funcionalidades
- Criar, editar e excluir eventos
- Arrastar eventos entre datas
- Definir lembretes para eventos
- Tema claro/escuro

## Stack
- Laravel (backend)
- Vue.js 3 (frontend)
- Inertia.js
- MySQL
